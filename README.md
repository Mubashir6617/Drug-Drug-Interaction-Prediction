# Drug-Drug-Interaction-Prediction
A practical, beginner-friendly Google Colab project for predicting potential Drug-Drug Interactions (DDIs) with traditional machine learning and graph-based deep learning.

This project implements and compares:

- Random Forest using handcrafted network and similarity features
- Graph Convolutional Network (GCN) autoencoder for DDI link prediction
- Evaluation with Accuracy, Precision, Recall, F1-score, ROC-AUC, PR-AUC, confusion matrices, ROC curves, Precision-Recall curves, and training curves

The notebook automatically downloads the public BioSNAP Decagon Combo dataset and is designed to run from top to bottom in Google Colab.
